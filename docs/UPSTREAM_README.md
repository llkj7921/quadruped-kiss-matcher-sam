# Upstream KISS-Matcher

This repository is derived from
[MIT-SPARK/KISS-Matcher](https://github.com/MIT-SPARK/KISS-Matcher).

The upstream project provides the KISS-Matcher point-cloud registration
library, C++ and Python examples, academic references, and its original
installation guide. Refer to the
[upstream README](https://github.com/MIT-SPARK/KISS-Matcher/blob/main/README.md)
for those materials.

This derivative retains the upstream Git history, copyright notices and MIT
license. GitHub therefore lists upstream authors in the contributor history.
The quadruped SLAM integration and ROS 2 back-end changes are maintained
independently and are not an official MIT-SPARK release.
